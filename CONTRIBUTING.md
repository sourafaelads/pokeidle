# Como contribuir 💜

Valeu pelo interesse em ajudar o PokeIdle Hub!

## Achou um bug ou tem uma ideia?

Abra uma [Issue](https://github.com/sourafaelads/pokeidle/issues/new/choose) e escolha:

- **🐞 Reportar bug** — algo não funcionou.
- **💡 Sugerir ideia** — função nova ou melhoria.

Antes, dê uma olhada se já não existe uma issue parecida.

## Quer mandar código?

1. Faça um **Fork** do repositório.
2. Crie um branch para a sua mudança: `git checkout -b minha-melhoria`.
3. Compile e teste no Windows: `cargo build --release`.
4. Abra um **Pull Request** explicando o que mudou e por quê.

### Regras do projeto

- **Leveza em primeiro lugar.** O app existe para rodar bem em PC fraco. Mudanças que aumentam RAM/CPU precisam de um bom motivo — e, se possível, de uma opção para desligar.
- **Só código.** Não envie `.exe`, `.dll` ou arquivos compilados. As versões oficiais são compiladas a partir do código revisado.
- **Nada de dados pessoais.** Não inclua logins, tokens, cookies ou o conteúdo de `%LOCALAPPDATA%\PokeIdleHub`.
- **Respeite o jogo.** Nada que altere o jogo, burle limites ou passe das regras (ex.: máximo de 4 contas).
- Comentários e textos da interface em **português**.

Obrigado! 🎮
